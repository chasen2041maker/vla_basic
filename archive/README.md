# 历史归档

这里保存旧课程、旧规划和当时的实验记录。历史文中的“当前”、能力状态、工具选型和旧路径均属于记录发生时，不覆盖现在的 [PROGRESS](../PROGRESS.md)。日常阅读请打开 [唯一教材](../learning/BOOK.zh-CN.md)。

`labs/` 保留旧专项代码、数据和测试，仍由根目录检查命令运行；从根目录手动运行旧命令时，路径使用 `archive/labs/`。`notes/` 保存历史来源与迁移证据，其中 JSON 中的路径和哈希是当时的快照。旧 Lab 和 H001 没有因归档被标为完成。

课程设计、前沿雷达、旧审查说明留作追溯，使用其中的岗位、工具状态或外部资料之前需要重新核实。
