## 4. 教学顺序：系统优先

用户最新阅读要求：讲解涉及的代码直接列在同一页，逐段解释，源码路径只作可选出处；不再要求反复跳文件。助手需主动检查整套教材的前置知识、术语密度与顺序，按已有 Python/AI/后端经验编写，不等待用户逐页报难读。默认阅读 `learning/BOOK.zh-CN.md`；其他规划与审查文档由助手维护，非必读课文。

2026-09-27 阅读反馈：用户按指引读 SYSTEM_MENTAL_MODEL.md 第 1.1 节，仍觉得晦涩。不能把资料地图直接当成初学讲义；正文先用一个具体驾驶例子与清楚的时间顺序，解释新词再出现接口名，源码边界和跨模块细节放后面按需展开。用户已能说明目标 20、实际 25 应下降，不重复用同一道数字题卡住教学。

新主题第一次出现时，按下面顺序讲：

```text
它解决什么真实驾驶问题
→ 位于整车系统哪个位置
→ 上游输入是什么
→ 下游输出是什么
→ 属于什么时间尺度
→ 位于什么坐标系
→ 它负责什么
→ 它不负责什么
→ 正常例子
→ 失败症状
→ 如何验证
→ 最后再拆代码和公式
```

不允许一上来只按文件和类逐行讲，而没有说明其系统意义。

自动驾驶领域强制追问：

```text
这个值是什么时间的？
这个值在哪个坐标系？
这个 action 是轨迹、token 还是单步控制？
这个指标是开放环还是闭环？
```

## 5. 两条学习通道

### Verify 通道

适用于深度学习训练、Transformer、蒸馏、量化、Linux/Git 等已有经验：

```text
不重复基础课
→ 给真实驾驶任务
→ 独立修改或排错
→ 用测试和实验确认
```

### Learn 通道

适用于视觉、几何、车辆运动、闭环评测和 VLA：

```text
系统全景
→ mental model
→ 可运行 reference
→ 小改
→ fault injection
→ tests/eval
→ 独立解释
```

## 6. Reference Implementation 要求

参考实现应：

- 规模适中且能直接运行；
- 输入输出契约显式；
- 时间戳、单位和坐标写进变量名；
- 含预期输出、tests 和 failure cases；
- 明确哪些是教学简化；
- 不用高级框架隐藏当前知识；
- 不要求从空白重复写无价值样板。

学习者至少完成：

```text
读懂 execution path
+ 独立修改一个关键行为
+ 写或改一个测试
+ 定位一个故障
+ 用自己的话解释边界
```

## 7. AI Coding 使用边界

允许使用 ChatGPT、Codex 和其他 Coding Agent，但必须保留以下能力：

- 不依赖 Agent 也能读懂核心执行链；
- 能用日志、断点、最小复现定位关键 bug；
- 能判断 Agent 生成的时间、坐标、action 和 evaluator 逻辑是否正确；
- 能解释最终代码为什么成立以及何时失效。

“Agent 写完、测试全绿”不能单独构成掌握证据。

## 8. 掌握状态

```text
ASSUMED  根据经验或自述暂时作为教学起点
LEARNING 当前系统学习
REVIEW   基本理解或学过，但仓库证据不足
PASSED   有代码、测试、实验和解释证据
REVISIT  曾经通过，但需要重新验证
```

## 9. 不应该做的事情

不要：

- 从 Python 或普通神经网络基础重新开始；
- 因为会训练模型就跳过视觉、几何和车辆运动；
- 先背 PPO、DPO、GRPO，再理解驾驶 state/action/rollout；
- 把机械臂 VLA 当驾驶 VLA；
- 一上来下载重型数据和框架；
- 用轨迹 L2 单指标代替驾驶能力；
- 把自然语言推理当作安全证明；
- 把量产闭源宣传写成可复现结果；
- 为了显得先进无条件加入 world model、RL、multi-agent 或 Kubernetes。

## 10. 项目式入口与中文带读（2026-09-22）

学习者确认：使用现有 `vla_basic`，跟着 HighwayEnv 做一个持续改进的驾驶项目，不另开仓库，不再次全量推倒旧内容。

近期方式是：**先看到车辆运行，再围绕具体行为补基础**。先解释当前问题的系统位置，不要求先学完系统地图、视觉、相机几何或全部旧 Lab 才能进入仿真。

旧 Lab 改为参考材料，未完成任务仍未完成。代码可运行、维护者 CI 通过和学习者个人掌握必须分开记录。

每次围绕同一项目：驾驶问题 → 运行当前版本 → 中文带读相关代码 → 学习者预测 → 一个小修改 → 用实验验证 → 记录结论。

英文变量和接口名保留；关键意图、单位、坐标、时间和失败边界用中文注释。读到旧代码的哪一处，再补哪一处，不为了翻译而重写全仓库。

当前唯一任务由 `PROGRESS.md` 指向；不要重复创建根目录任务文件，也不要一个概念建一个 Demo。长期 VLA 目标保留，初期模拟器状态决策不冒充视觉感知或 VLA。
