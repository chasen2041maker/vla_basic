# 学习者背景与偏好

这份文件记录会长期影响教学方式的背景。会变化的学习位置只看 [PROGRESS](../PROGRESS.md)。旧的逐条累积版本在 [archive/notes/2026-10-07-learner-profile-before-readability-rewrite.md](../archive/notes/2026-10-07-learner-profile-before-readability-rewrite.md)。

## 背景

- **学历**：UNSW 硕士，AI 方向（2023.09–2025.10）；本科生物工程。
- **工作**：2026.04 起做 AI 应用后端，Python / Go 服务、数据处理、接口集成、评测与交付。
- **熟悉**：Python、Agent / workflow、RAG、tool calling、AI Coding；能读工程代码。
- **做过**：常规深度学习训练；BERT 双分支分类、Qwen2 微调、蒸馏与 INT8 量化的个人项目。
- **C++**：学校学过，需要在实际模块里恢复手感。
- **还没学**：强化学习；在本项目之前没有系统学过智能驾驶。视觉、相机几何、车辆运动、轨迹规划、控制、闭环评测都从这个项目开始建立。

## 教学上怎么用这些背景

| 已有基础 | 怎么教 |
| --- | --- |
| Python、训练循环、Transformer、蒸馏量化、Linux / Git | 不重讲基础，直接放进驾驶任务里用 |
| 视觉、几何、车辆运动、轨迹、闭环评测、VLA | 新内容，从具体驾驶问题和可运行的小实验开始 |

| 强化学习 | 等 state / action / 闭环都清楚了再进入（阶段 2 的 DQN 对比） |

## 学习偏好

- **直白**：先用一两句日常话回答，再用一个看得见的现象说明。“说了一堆、太专业”的解释不要。
- **短段 + 动手**：读一小段就运行一个能看到效果的实验，再亲手改一个参数、比较变化。不喜欢长时间只读文字。
- **代码就地**：讲到的代码直接贴出来，附完整路径和方法名；不要让我在几个文件之间来回跳。
- **以源码和现象为入口**：当前阶段跟着 HighwayEnv 源码学，教材当复习和查阅用。
- **工具**：Windows + VS Code + PowerShell；Conda 环境 `py310`。
- 已经答对的问题不要反复考。

## 目标

**长期**：进入智能驾驶研发链，最终方向是驾驶 VLA / 端到端模型这一类，而不是只会调 API。

**近期求职**：车企自己的智能驾驶团队，杭州优先、上海其次，月薪 20k 以上。

当前比较适合切入的方向（结合后端和评测经验）：仿真评测工具 / 平台、数据闭环与场景挖掘、模型工具链。算法方向作为持续深入的目标，需要逐步补齐对应作品。

希望最终能做到：

```text
看到一条驾驶数据 → 说清字段、单位、时间和坐标
→ 画出从传感器到车辆运动的完整链
→ 训练并修改一个轨迹模型
→ 出问题时分清是数据、模型、动作、控制、评测还是系统的问题
→ 比较开环和闭环表现
→ 做压缩部署实验，并说清楚安全边界
```

## 还需要确认的事

- 薪资口径：税前 / 税后、月薪 / 总包、几个月。
- 每周能投入多少时间，计划多久转岗。
- 可用硬件（有没有 GPU）。
- 校招 / 社招资格：按学位授予时间和企业批次核对。

## 学习状态标记（阶段完成时用）

```text
LEARNING  正在学
REVIEW    基本理解，但还缺代码或实验证明
PASSED    有代码、实验和自己的解释
```

平时不逐条打标记，只在一个阶段完成时简短判断一次。
